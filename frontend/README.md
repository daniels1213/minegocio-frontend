# Frontend Project

## Overview
This project is a Vue.js application that serves as the frontend for the MiNegocio1.0 project. It is built using Vite for fast development and build processes.

## Project Structure
```
frontend
├── src
│   ├── App.vue
│   ├── main.ts
│   └── assets
│       └── styles.css
├── package.json
├── tsconfig.json
├── vite.config.ts
├── index.html
├── README.md
└── .gitignore
```

## Getting Started

### Prerequisites
- Node.js (version 14 or higher)
- Yarn (version 1.22 or higher)

### Installation
1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd frontend
   ```
3. Install the dependencies:
   ```
   yarn install
   ```

### Running the Project
To start the development server, run:
```
yarn dev
```
This will launch the application in development mode.

### Building the Project
To build the project for production, run:
```
yarn build
```

### Previewing the Build
To preview the production build, run:
```
yarn preview
```
